# Portal Pengumuman Kelulusan

Halaman statis untuk GitHub Pages, disalin dari `website/pengumuman-kelulusan.html`. Data contoh siswa dihapus sebelum dipublikasikan.

## Batasan versi ini

- Data siswa, pengaturan, dan PIN disimpan di `localStorage` pada browser masing-masing. Perubahan dari satu perangkat tidak dibagikan ke perangkat lain.
- Panel PIN berada di sisi browser, sehingga bukan autentikasi aman untuk mengelola data publik.
- Jangan gunakan untuk data siswa sungguhan sebelum ada backend bersama dengan akses admin yang aman.
